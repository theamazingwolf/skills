# wlf-skills

The plugin that bundles every skill in this pack, by Tim Wolf. Install,
requirements, the skill list and the command list are in the
[repository README](../../README.md).

| Skill | Commands |
|---|---|
| [wlf-jev](skills/wlf-jev/) | `/wlf-skills:jev-setup`, `jev-explain`, `jev-design`, `jev-calibrate`, `jev-integrate`, `jev-run` |

Data notice: whatever goes into a Jev question's `state` is sent to
TypeSafe. Not affiliated with or endorsed by TypeSafe. TypeSafe and Jev
are trademarks of their respective owners.
