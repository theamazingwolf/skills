# Changelog

All notable changes to the wlf-skills plugin are documented here. Format
follows Keep a Changelog and adheres to semver.

## [1.0.0] — 2026-11-02

### Added
- First public release of the `wlf-skills` plugin in the `theamazingwolf`
  marketplace (one bundled plugin, source at the repo root).
- `wlf-jev` skill: design, integrate, calibrate and run TypeSafe Jev
  questions (noul, choice, score, box), with references, a calibration
  script, a question runner with offline mock mode, four TypeScript
  starters and a visual explainer.
- Slash commands `jev-setup`, `jev-explain`, `jev-design`, `jev-calibrate`,
  `jev-integrate`, `jev-run` (each a thin entry point into one wlf-jev mode).
